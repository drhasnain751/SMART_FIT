API Overview

The SmartFit AI API is designed to generate personalized workout and diet plans using user profile data. The recent update introduces a full authentication workflow, making endpoints secure for multi-user environments.

What's New

✨ Full JWT authentication system for secure multi-user access
🔒 Protected endpoints for workout and diet plan generation
📊 Enhanced error handling with detailed validation messages
🎯 Production-ready architecture for web and mobile apps

Authentication System

POST /api/v1/auth/register

Register a new user account

email string (required)
password string (required)
201 Created
Success Response 
{
  "email": "user@example.com",
  "id": 5
}
422 Validation Error
POST /api/v1/auth/token

Authenticate and receive JWT bearer token

username string (form-data)
password string (form-data)
grant_type string (form-data, default: "password")
200 OK
Success Response 
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}

Security Note

All generator endpoints require a valid JWT via Authorization: Bearer <token> header.

AI Generators

POST /api/v1/generate-workout Auth Required

Generate a personalized multi-day workout plan based on user profile

Request Body 
{
  "activity_level": 1.55,
  "age": 28,
  "available_equipment": ["Body Weight", "Dumbbell"],
  "gender": "male",
  "goal": "muscle_gain",
  "height_cm": 180,
  "user_level": "Beginner",
  "weight_kg": 80
}
200 OK
Success Response 
{
  "workout_plan": {
    "Day 1: Push": [
      {
        "Exercise": "Hammer Grip Incline DB Bench Press",
        "BodyPart": "Chest",
        "SetsReps": "3-4 sets of 8-12 reps"
      }
    ],
    "Day 2: Pull": [...],
    "Day 3: Legs": [...],
    "Day 4: Core": [...]
  }
}
cURL Example 
curl -X POST "http://127.0.0.1:8000/api/v1/generate-workout" \
  -H "accept: application/json" \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "activity_level": 1.55,
    "age": 28,
    "available_equipment": ["Body Weight", "Dumbbell"],
    "gender": "male",
    "goal": "muscle_gain",
    "height_cm": 180,
    "user_level": "Beginner",
    "weight_kg": 80
  }'

Response Formats & Error Handling

Response Standards

✅ Successful requests return well-structured JSON with substantive data
❌ HTTP 422 returned for missing fields/invalid data with location-message-type schema
🔒 HTTP 401 Unauthorized for missing/invalid authentication tokens
📋 All responses include detailed validation messages to guide developers
